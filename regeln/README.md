# Regeln

Lies zuerst **`REGELN.md`**. Sie gilt vor allen anderen Dateien und wird mit jedem neuen Learning ergänzt (mit Datum).

| Datei | Inhalt |
|---|---|
| `REGELN.md` | Haltung, Thema, Gerüst, Hook, Text, Titel, Thumbnail, Upload: die eine Quelle |
| `hook-bauplan.md` | Wie die ersten 60 Sekunden gebaut werden, mit Daten |
| `treffer-check.md` | Wie ein Thema auf Nachfrage geprüft wird |
| `clip-schritt.md` | Interview-Clips: Auswahl, Länge, Anteil |
| `vibe-brief.md` | Das Gefühl des Kanals in einer Seite |
| `feedback-log.md` | Jakobs Rückmeldungen, aus denen die Regeln entstanden sind |
| `regeln-befund-2026-11-06.md` | Welche älteren Regeln sich widersprachen und wie es aufgelöst ist |
| `skills/` | Alle Claude-Skills des Kanals (Thema/Titel, Skript, Animation, Motion-Handwerk, Thumbnails, Upload, Wochenanalyse), Stand 26.11.2026. Übersicht: `docs/building-blocks.md` |

Die Arbeitsfassung liegt im Projektordner (`schreibraum/REGELN.md`). `python3 tools/sync_projektordner.py` holt sie hierher.
Die Skills werden in Claude gepflegt; die Kopien hier sind zum Lesen und Weitergeben.
