# Fluid Motion Design

Goal: one living shot, never a slideshow. Test: "Would this work as a slide?" If yes, redo.

## Rules

1. **One continuous shot, no cuts.** Transform into the next scene every 1-2 s.
2. **Everything moves, always.** Slow is not still. Hero motion leads, ambient motion stays subordinate.
3. **Snappy.** Fast ease-in, hard stop, overshoot-and-settle. Never linear. Hits land on the beat.
4. **Weight must be felt.**
   - Heavy: slow start, big anticipation, short hard stop, squash on impact, camera shake, long settle, trailing secondary motion.
   - Light: quick start, bouncy overshoot, floaty settle.
   - Impact transfers energy: heavy hits light, light flies off. Vary weight on purpose.
5. **Hard speed contrast.** Whips against slow, floaty moments.
6. **Objects influence each other.** Push, collide, ripple, cast light. Energy leaving A drives B.
7. **Eye tracing.** End point of beat n = start point of beat n+1.
8. **Alternate wide and close-up.**
9. **Invisible seams.** Start the next move before the last one ends. Keep one anchor constant (shape, color, vector, scale) and let momentum carry through.
10. **Every frame is a keeper.** Motion blur on fast moves.
11. **Composition: symmetric or radically asymmetric.** Nothing in between.
12. **Depth.** 3+ parallax layers, camera moves along one continuous path.
13. **12 principles of animation,** especially anticipation, squash and stretch, follow-through, arcs, timing, exaggeration.
14. **One idea per beat.** Text only as 1-3 words, integrated into the scene. One visual language (palette, light, material).
15. **Rhythm and arc.** Beat grid with sound hits. Hook, build, peak, resolve. Each transformation is a visual metaphor.

## Avoid

Bullets, fades, wipes, cut to black, uniform timing, linear easing, static centered layouts.

## QC

Freeze-frame test (every frame a keeper), seam test (can't see where a transition starts), stillness test (nothing frozen), weight test (can you feel heavy vs light), slide test.
