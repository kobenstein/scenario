**Was v2 ändert**

2. **Zwei Ebenen.** Jeder Shot ist **[3D]** (die Welt, Kamera im Tal) oder **[EXPL]** (die Explainer-Ebene: Licht auf Nacht, wächst aus einem Objekt der Welt). ≈ 37 % der Laufzeit c02–c12 sind [EXPL] (§4).
3. **Jeder Wechsel hat einen notierten Träger:** `A → B · Position · Richtung`. Kein Wechsel ohne Träger, keine Blenden, keine Wipes.

## §1 Lesehilfe
- **ID** = Chunk.Nummer. **Zeit** = von–bis in Filmsekunden; ein Shot beginnt mit seinem ersten VO-Wort und läuft bis zum nächsten; Pausen gehören dem Shot davor (die Bewegung läuft weiter).
- **Ebene**: `3D` = Welt; `EXPL` = Explainer-Ebene nach MOTION.md §13 (Grafik aus Licht, Kamera fährt **in** die Grafik hinein und wieder heraus, nie ein Rechteck-Panel, nie ein gerahmtes Label). `3D→EXPL` / `EXPL→3D` = der Shot enthält die Verwandlung.
- **Anker** = Akzentwort `@` Sekunde. Im Code immer über das Wort ankern (`T.S('01a','joint')`), nie über die Sekunde.
- **Bewegung** = höchstens 2 Hauptbewegungen (Kamera zählt mit). Umgebungsleben (Atmen, Sterne, Nebel, Korn) ist immer da und zählt nicht.
- **Übergang → Träger**: Art · `Träger A → B` · Bildposition · Richtung. Arten: **Plansequenz** (gleiche Einstellung), **Fahrt**, **Verwandlung** (Form wird Form, MOTION.md §13.2 T1–T6), **Flug** (in eine Fläche hinein), **Clip-Schnitt**, **SCHNITT** (Budget ≤ 3, belegt: 1).
- **Held** (im Chunk-Kopf) = das eine warme Helden-Licht; im Code `K.heroLight({...})` pro Frame registrieren. Wechselt der Held innerhalb des Chunks, steht es im Shot.
- ★ = der eine Wow-Shot pro Chunk (erstes Standbild an Jakob, bevor der Rest des Chunks gebaut wird).
- Ruhe-Regeln (gelten für jeden Shot): Halten 1,5–3 s nach jedem Akzent · MAFD ≤ 0,5 außerhalb von Fahrten (`calm.py`) · max. 1–2 bewegte Hauptelemente · Zahlen und Labels stehen ≥ 1,5 s ruhig, bevor etwas anderes sich bewegt.
- Was in v1 genauer beschrieben ist (Requisiten, Gesten), gilt weiter, wenn v2 nichts anderes sagt: „wie v1“ = siehe `shots-v1.md`, gleiche ID.
