# Film 76 · "Your Kids Will Grow Up With Superintelligence" (The Good Takeoff) · code

Editorial-night machine of Films 59–68 (Node + @napi-rs/canvas), copied from #68 and rebuilt. Leitbild: thumbnail C, parent and child walk
hand in hand up a ramp to a giant gate of gold light (anchors only: h1, h11, s4, s6).
- Plan: `docs/MOTION.md` (REGELN §13 checklist, stages, carrier, wow, colour code, Nicht wiederholen, measurements) · `docs/shots.md`
  (one row per sentence, "zeigt wörtlich", "Motiv neu?", share on top; generated by `tools/shots76.mjs` from `scenes/plan.mjs`) ·
  `docs/BRIEF-builders.md` (packages B1/B2/B3).
- Sequencer: `film.mjs` resolves the shots of `scenes/plan.mjs` on the VO timing (`scenes/resolve.mjs`); every boundary is the paper plane
  (arc flight .55 s + disc reveal .7 s) or a match, 0 hard cuts. Draws: `scenes/ch_hook.mjs` (lead, h1–h12), `ch_b1|ch_b2|ch_b3.mjs`.
- Kit: `lib/f76_kit.mjs` (re-exports `lib/f68_kit.mjs` → `lib/f67_kit.mjs`: clip plates, cards, sources).
- ROOT (small files, network mount): `/mnt/project-files/scenario/film-76-kinder/` (`$F76ROOT`). Renders: `/tmp/claude-0/f76/`.
- Timing: `<ROOT>audio/timing.json` (real VO) if present, else `data/provisional_timing.json` (`python3 tools/provisional_timing.py`, newest vo-vN).
- Clip frames: `/tmp/claude-0/f76/clips/C1|C2|C4|C5/` from `films/76-assets/clips/` (`tools/f76_clips.py`, after branch `claude/f76-imac`).
- `audio/` is still the #68 copy; the sound step adapts it.
