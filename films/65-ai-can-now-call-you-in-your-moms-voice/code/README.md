## Commands
- **Footage frames** (once): `F65SCRATCH=<scratch>/f65 python3 tools/f65_film.py clips` (S1, C1, S2 as 30 fps jpgs; the kit reads `$F65SCRATCH/clips`).
- **Stills:** `SECS=c01 node render.mjs --snap 1,5 --dir D --scale .4`
- **Video:** `SECS=c01 node --expose-gc render.mjs --out x.mp4 --from 0 --to 20 --scale .5`
- **Kit sheet:** `node tools/kit_sheet65.mjs <dir> [scale] [only,…]`
- **Checks:**
  - `python3 tools/calm.py x.mp4 --scale 1280:720`
  - `python3 tools/smooth.py x.mp4 <start>`
  - `SECS=c01,c02 node tools/seam.mjs --at 59.35`
- **Final:** `python3 tools/f65_film.py render` → `assemble --name fassung-1` (subtitles burned in, the mix under it, **no QR overlay**).
